Твой ход

🏎 Гонка

Управление: стрелочки ← ↑ → ↓. Shift — ускорение. Доедь до финиша, объезжая препятствия. Твоё время сохраняется как лучший результат.
До финиша: 100%
Счёт: 0 Лучшее время: — Скорость: 1×

🧩 Тетрис

Клавиши ← → — движение, ↑ / клик — вращение, ↓ — ускорить, Space — мгновенно вниз.
Счёт: 0
Рекорд: 0
Линий: 0

🐍 Змейка

Управление: стрелочки ← ↑ → ↓ или WASD. Собирай яблоки, чтобы расти. Врезался в границу или в себя — проиграл. Рекорд сохраняется.
Счёт: 0
Рекорд: 0
Длина: 3
